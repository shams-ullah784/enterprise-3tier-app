# Enterprise TaskFlow (3-Tier Application)

Welcome to the **Enterprise TaskFlow** project! This is a complete 3-tier enterprise application built with a modern tech stack, fully containerized using Docker, and automated with CI/CD pipelines via GitHub Actions.

---

## 🚀 Tech Stack
* **Frontend:** React, Vite, Nginx
* **Backend:** Python, FastAPI / Flask
* **Database:** MySQL
* **Containerization:** Docker & Docker Compose
* **CI/CD:** GitHub Actions (Automated Deployment to AWS EC2)

---

## ✨ Features
* User-friendly frontend interface.
* Secure RESTful API backend.
* Reliable database integration.
* Automated CI/CD deployment pipeline directly to an AWS EC2 instance.
